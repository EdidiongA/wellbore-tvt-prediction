# EAGE Submission Summary (≤200 words)

**Edidiong Anwanane**


Blind-zone true vertical thickness (TVT) prediction in horizontal wells is reframed as tracking a single smooth structural coordinate, u = TVT + Z, which separates geology from the exactly-known well path. A second-order (u, dip) hidden-state tracker with a merged typewell reference and an inverse-variance-fused spatial field reduces error on a 6,125-team industry benchmark from a 15.88 ft baseline to 8.91 ft, at ~4 s per well on one CPU. A validation protocol built on deliberate probe submissions — a fitted local-to-leaderboard transfer law, a synthetic-corruption suite with earned veto power, and pre-registered exploitability probes — then establishes the residual as input-limited: a sequence model on identical inputs converges to the same regime, and per-well heterogeneity is bounded but unpredictable. Deployment-side dose-response mapping locates interior optima on four axes (structural damping, high-frequency shrinkage, signed drift, drift profile), reaching 8.72 ft public and 8.354 ft private — top 4% (Silver medal). The final private split inverts several public-subset conclusions, yielding the central caution: every finite evaluation set imposes its own optimum; only structure-grounded mechanisms transferred across all three splits.
